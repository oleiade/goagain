Quick Start

Docker Run locally

docker run -p 8080:8080 ghcr.io/oleiade/goagain:latest

REST API Search for cards

curl "https://api.goagain.dev/v1/cards?name=Strike&class=Warrior&limit=5"

REST API Get card details

curl "https://api.goagain.dev/v1/cards/enlightened-strike-red"

MCP Add to Claude Desktop

Add this to your Claude Desktop configuration file:

{
  "mcpServers": {
    "flesh-and-blood": {
      "url": "https://mcp.goagain.dev/"
    }
  }
}

Try it Example prompts

Once configured, ask Claude questions like:

  • "What Ninja attacks have go again?"
  • "Show me all Briar cards legal in Classic Constructed"
  • "Compare Enlightened Strike to Razor Reflex"

API Endpoints

Endpoint Description
GET /v1/cards Search cards with filters (name, type, class, set, pitch, keyword, q, legal_in)
GET /v1/cards/{id} Get card by unique ID or name
GET /v1/cards/{id}/legality Get card legality across all formats
GET /v1/sets List all card sets
GET /v1/sets/{id} Get set details with cards
GET /v1/keywords List all game keywords
GET /v1/keywords/{name} Get keyword description
GET /v1/abilities List all card abilities
GET /openapi OpenAPI specification (YAML)
GET /health Health check with data statistics

Frequently Asked Questions

Is there a Flesh and Blood card database API?

Yes! goagain provides a free REST API for Flesh and Blood TCG card data. You can search cards, filter by class, type, keywords, and check format legality. No API key or authentication required.

How do I get FaB card data for my project?

Make HTTP requests to api.goagain.dev endpoints. For example, GET /v1/cards?class=Ninja returns all Ninja cards. The API supports JSON responses and CORS, so you can call it directly from web apps.

Can I use Claude to look up Flesh and Blood cards?

Yes! goagain includes an MCP server that works with Claude Desktop and other AI assistants. Add the MCP configuration to Claude, then ask questions like "What Ninja attacks have go again?" or "Show me Briar cards legal in CC."

Does this API require authentication?

No authentication required. The API is free and open for everyone. Rate limiting is applied to ensure fair usage, but there are no API keys or signup needed to start querying card data.
